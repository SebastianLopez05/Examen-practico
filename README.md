# Algoritmo de Compresión de Imágenes con Quadtree (Divide y Vencerás)

Prototipo funcional para la compresión y reconstrucción de imágenes digitales utilizando la estructura jerárquica Quadtree y el enfoque Divide y Vencerás.

## Requisitos e Instalación

Para instalar las dependencias necesarias, ejecuta en la terminal:

```bash
pip install -r requirements.txt

Ejecutar la suite completa de experimentos:

PowerShell
python experiments/run_experiments.py}

Probar el Programa 

Ejecuta el experimento: Llama al script run_experiments.py 

Tip (Arrastrar imagen en Windows): Si prefieres indicar una imagen guardada en otra ubicación (como Descargas o Imágenes), ejecuta el script pasándole la ruta como parámetro:

python experiments/run_experiments.py "C:\Ruta\A\Tu\mi_imagen.png"
